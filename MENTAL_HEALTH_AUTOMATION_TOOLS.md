# Mental Health Automation Tools from GitHub
**For people with bipolar, depression, ADHD, and neurodivergence who need systems that work with their brain, not against it.**

---

## Philosophy

These tools share common principles:

✓ **Reduce decision fatigue** — Decisions when you're depressed are paralyzing
✓ **Forgive bad days** — System keeps working even when you can't
✓ **Visual feedback** — See progress to combat imposter syndrome
✓ **Low barrier to entry** — No setup paralysis, fast to start
✓ **Open source** — You own the code, privacy, no corporate tracking
✓ **Offline-capable** — Doesn't require internet (good for disconnecting days)

## 1. HABIT TRACKERS

### Habitica
- **GitHub:** https://github.com/HabitRPG/habitica
- **What:** Turns your habits into an RPG game
- **Why for mental health:** Gamification reduces shame. You're a character leveling up, not failing.
- **Features:** Habit tracking, daily quests, party system (accountability with others)
- **Setup time:** 10 minutes
- **Cost:** Free
- **Self-hostable:** Yes (Docker available)

### Goalify
- **GitHub:** https://github.com/kaustubhgupta/Goalify
- **What:** Simple goal tracker with visual progress
- **Why:** See progress visually. "I did 4/5 days this week" is powerful for depression.
- **Setup time:** 5 minutes
- **Cost:** Free
- **Self-hostable:** Yes

### Loop Habit Tracker
- **GitHub:** https://github.com/iSoron/loop_habit_tracker
- **What:** Minimal habit tracking app (Android + Desktop)
- **Why:** Ultra-simple. No overwhelm. Just: did you do it? Yes/No.
- **Setup time:** 2 minutes
- **Cost:** Free
- **Works offline:** Yes

## Why These Tools Are Therapeutic

### For Bipolar Disorder
- **Mood tracking** reveals patterns → can prepare for episode triggers
- **Medication reminders** prevent missed doses → avoid destabilization
- **Gamification (Habitica)** gives dopamine hits on hard days
- **Routine tools** create stability when mood swings create chaos

### For Depression
- **Habit trackers with visual progress** fight "I'm not doing anything" feelings
- **Low-friction tools** (fewer clicks) work when energy is low
- **Offline capability** = no anxiety about being tracked
- **Automation** = consistent output when motivation is zero

### For ADHD
- **Pomodoro timers** break tasks into manageable chunks
- **Body doubling** features help with focus
- **Time blocking** prevents hyperfocus from destroying sleep schedule
- **Notifications** replace faulty internal memory

### For Neurodivergence (General)
- **Minimal interfaces** reduce overwhelming options
- **Open source** means you understand the code (no hidden tracking)
- **Offline-first** design = works when internet fails
- **Local storage** = privacy + control

## Common Questions

**Q: Should I use all of these?**
A: No. Start with 1-2. Add more if the first ones help. Too many tools = cognitive load = defeats the purpose.

**Q: What if I don't use them for a week?**
A: That's okay. Mental health is non-linear. The tool should be forgiving. Good tools don't shame you.

**Q: Can I use these on my phone?**
A: Most have mobile versions or work in mobile browsers. Check their GitHub pages.

**Q: Is my data safe?**
A: If self-hosted (Nextcloud, Joplin) = your server, your data. If web-based (Habitica, Todoist) = depends on terms. Read their privacy policy.

**Q: How do I connect these tools to each other?**
A: That's where **Zapier** or **n8n** come in (automation). Or you can write your own scripts (like the Sheets Publisher).

You're not broken. Your brain works differently. These tools aren't "crutches" — they're **accommodations**.

Like glasses for poor eyesight.
Like ramps for wheelchair users.

That's not weakness.

Use them. You deserve systems that work *with* you.
