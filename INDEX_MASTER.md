## 🚀 Quick-Start Paths (Pick Your Style)

### Path A: "I Just Want to Publish Posts" (15 minutes)
1. Download **Python Desktop App**
   ```bash
   python tools/wp-desktop.py
   ```
2. Enter credentials (Settings tab)
3. Type a topic → Click Generate → Click Publish
4. Done

**Cost:** $0
**Time per post:** 5 minutes (AI generates everything)

---

### Path B: "I Have a Google Sheets Habit" (30 minutes)
1. Open Google Sheets
2. Extensions → Apps Script
3. Paste code from `tools/sheets-publisher.js`
4. Run setup functions
5. Add posts to Sheets with Status=READY
6. Automatic hourly publishing

**Cost:** $0
**Time per post:** 3 minutes (just add a row)

---

### Path C: "I Use GitHub" (20 minutes)
1. Set GitHub Secrets: WP_URL, WP_API_KEY, CLAUDE_KEY
2. Create `posts/my-post.md` with frontmatter
3. Push to GitHub
4. Automatically published via GitHub Actions

**Cost:** $0
**Time per post:** 5 minutes (write + push)

---

### Path D: "I Want to Fix My Mental Health" (2 hours)
1. Install Loop Habit Tracker (medication, routine)
2. Install MindYou (mood tracking)
3. Set up Sheets Publisher (content automation)
4. Optional: Joplin (private notes), Nextcloud (data privacy)

**Cost:** $0-5/month
**Time:** 2 hours setup, then 10 min/day
