## 6. Password Management

### Recommended Password Managers

1. **Bitwarden** (Free & Open Source)
   - Self-host option available
   - Cross-platform
   - Browser extensions
   - Mobile apps

2. **1Password** (Premium)
   - Excellent UI/UX
   - Family/team sharing
   - Travel mode for security

3. **LastPass** (Freemium)
   - Easy to use
   - Browser extensions
   - Emergency access feature

4. **KeePass** (Free & Open Source)
   - Offline storage
   - Highly secure
   - Plugin ecosystem

### Password Management Best Practices

1. **Use Strong Passwords:**
   - Minimum 16 characters
   - Mixed case (upper and lower)
   - Numbers and symbols
   - No dictionary words
   - Unique for each service

2. **Enable 2FA Everywhere:**
   - Use authenticator apps (Google Authenticator, Authy)
   - Avoid SMS 2FA when possible (less secure)
   - Save backup codes securely

3. **Secure Your Password Manager:**
   - Use strong master password
   - Enable 2FA on password manager
   - Use biometric login (fingerprint/face ID)
   - Regularly audit access

4. **Share Securely:**
   - Use password manager's sharing features
   - Never share via email or chat
   - Use emergency access for trusted contacts
